# 캐러셀 (carousel)

시작은 `carousel` 스킬. 맨 위 머리말은 `npm run check`가 검사하는 규격이다.

## 지킬 것
- 4:5 세로 1080×1350 PNG, 버전 폴더마다 2~20장.
- 파일 이름은 장 순서대로 `01.png` `02.png` ….
- 첫 장 후킹 카피는 레퍼런스의 후킹 **구조**만 가져오고 문장은 새로 쓴다.
- 숫자 · 사례는 소재(원본 영상 · 기사)에 있는 것만.

## 기본값 (요청이 다르면 요청을 따른다)
- 8~10장: 후킹 1장 → 본문 → 정리 → 마지막 장 행동 유도(저장 · 댓글 · 팔로우)
- 한 장에 한 메시지, 글자는 휴대폰에서 읽히는 크기
- 버전은 기본 하나 (`v1-레퍼런스형`). "하나 더"일 때만 `v2-변형`
- 이미지 생성(Higgsfield)은 크레딧을 먼저 확인한다.
