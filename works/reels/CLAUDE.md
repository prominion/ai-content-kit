# 릴스 (reels)

시작은 `reels` 스킬. 맨 위 머리말은 `npm run check`가 검사하는 규격이다.

## 지킬 것
- 세로 1080×1920, 5~90초, 소리 있음.
- 자막 · 그래픽은 인스타 UI와 겹치지 않게 위 약 250px · 아래 약 350px를 비운다 (대략값, 실측 전).
- 자막은 말한 내용만 쓴다. 오탈자만 고친다.
- 렌더는 한 번에 하나. 다른 렌더가 돌고 있으면 기다린다.

## 기본값 (요청이 다르면 요청을 따른다)
- 버전은 기본 하나 (`v1-레퍼런스형`). "하나 더"일 때만 `v2-변형`
- 컷: 무음 · 말 더듬음 · NG 삭제, 타이트하게
- 얼굴과 모션그래픽을 교차
- 자막: 말 단위, 한 줄 18자 안팎
- 효과음: 전환마다 짧게, 말을 가리지 않게
