# 상세페이지 (detail-page)

시작은 `detail-page` 스킬. 맨 위 머리말은 `npm run check`가 검사하는 규격이다. (`max_mb`는 빌더 제한을 실측하기 전 임시값)

## 지킬 것 (완성 기준)
- 이미지 · GIF까지 들어간 HTML 한 파일. 내 컴퓨터의 다른 파일을 가리키지 않는다 (웹 폰트 CDN 링크만 예외). 빌더에 올릴 것은 `완성/<버전>/빌더용.html`.
- 가격 · 일정 · 혜택 · 후기 · 수익 인증은 `brand/<브랜드>/products/` · `assets/`에 있는 것만. 없는 것은 「입력 필요」로 비워 두고, 빈칸이 남으면 완성이 아니다.
- 실제 인물(본인 포함)은 이미지 생성으로 만들지 않고 `brand/<브랜드>/assets/`의 사진을 쓴다.
- 휴대폰 폭(375px)에서 글자 잘림 · 겹침 · 가로 넘침이 없다. 강사(판매자) 소개와 후기 섹션이 들어 있다.
