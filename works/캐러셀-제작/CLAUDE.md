# 캐러셀 (carousel)

시작은 `carousel` 스킬. 맨 위 머리말은 `npm run check`가 검사하는 규격이다.

## 지킬 것 (완성 기준)
- 4:5 세로 1080×1350 PNG, 버전 폴더마다 2~20장, 파일 이름은 장 순서대로 `01.png` `02.png` ….
- 한 장에 한 메시지, 글자는 휴대폰에서 읽히는 크기. 글자 잘림 · 겹침이 없다.
- 게시 문구 `완성/<버전>/캡션.md`가 함께 있다.

## 기본값 (요청이 다르면 요청을 따른다)
- 8~10장: 후킹 1장 → 본문 → 정리 → 마지막 장 행동 유도(저장 · 댓글 · 팔로우)
