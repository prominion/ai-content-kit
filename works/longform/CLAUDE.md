# 롱폼 (longform)

시작은 `longform` 스킬. 맨 위 머리말은 `npm run check`가 검사하는 규격이다.

## 지킬 것
- 가로 1920×1080, 1~20분, 소리 있음.
- 번역 자막은 원래 말의 뜻을 바꾸지 않는다. 내 해설과 화자의 말을 섞지 않는다.
- 남의 영상을 쓰면 출처(채널 · 링크)를 `작업.md` 「2. 재료」와 `완성/설명.md`에 적는다. 어디까지 써도 되는지는 사용자가 판단한다.

## 기본값 (요청이 다르면 요청을 따른다)
- 길이 5분 안팎
- 반복 단위: 화자 발화(+번역 자막 + 모션그래픽) → 내 음성 짧은 해설 → 다음 화자 발화
- 해설 자막에 "OO 코멘트" 같은 이름표를 붙이지 않는다.
- 내 음성은 `voice` 스킬 (`brand/<브랜드>/profile.md`의 음성 ID).
