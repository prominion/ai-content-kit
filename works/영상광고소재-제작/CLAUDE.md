# 광고소재 (ad-creative)

시작은 `ad-creative` 스킬. 맨 위 머리말은 `npm run check`가 검사하는 규격이다.

## 지킬 것 (완성 기준)
- 세로 1080×1920, 6~60초, 소리 있음.
- 자막 · 그래픽은 위 약 250px · 아래 약 350px를 비운다 (대략값, 실측 전).

## 기본값 (요청이 다르면 요청을 따른다)
- 첫 3초에 후킹, 속도감 있게. 효과음은 흐름을 방해하지 않게 짧게.
