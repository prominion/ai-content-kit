# 광고소재 (ad-creative)

시작은 `ad-creative` 스킬. 맨 위 머리말은 `npm run check`가 검사하는 규격이다.

## 지킬 것
- 세로 1080×1920, 6~60초, 소리 있음.
- 수익 인증 · 후기 · 숫자는 연결한 상세페이지와 `brand/`에 있는 것만 쓴다.
- 대본은 `대본.md`에 먼저 쓰고 사용자 확인을 받은 뒤 편집한다.
- 자막 · 그래픽은 위 약 250px · 아래 약 350px를 비운다 (대략값, 실측 전).

## 기본값 (요청이 다르면 요청을 따른다)
- 첫 3초에 후킹, 속도감 있게
- 버전은 기본 하나 (`v1-레퍼런스형`). "하나 더"일 때만 `v2-변형`
- 음성은 `voice` 스킬로 생성, 보통보다 조금 빠르게
- 효과음: 흐름을 방해하지 않게 짧게
