# AI 콘텐츠 키트 v1

잘된 콘텐츠를 레퍼런스로 모으고, 그 패턴으로 상세페이지 · 릴스 · 롱폼 · 캐러셀 · 광고소재를 매번 같은 방식으로 만드는 Claude Code 작업 공간입니다.

## 준비물
- Claude 유료 요금제 + Claude Code (데스크톱 앱 또는 터미널)
- Node 22 이상, FFmpeg (맥: `brew install node ffmpeg`)
- Higgsfield · Fish Audio 계정과 크레딧 (이미지 · 음성을 쓸 때)

## 시작하기
1. 이 폴더를 Claude Code로 엽니다. **항상 이 폴더에서 엽니다** (하위 폴더에서 열면 설정이 안 읽힙니다).
2. 처음 열면 `.mcp.json`의 커넥터(Higgsfield · Fish Audio · Meta) 승인 창이 뜹니다. claude.ai에서 이미 같은 커넥터를 연결했다면 거절해도 됩니다.
3. 사업마다 브랜드를 만듭니다: "브랜드 만들어줘, 이름은 ○○" (또는 `npm run brand -- ○○`). `brand/○○/profile.md`를 채우면 그 사업의 모든 작업이 이 파일을 먼저 읽습니다.
4. 잘된 콘텐츠를 레퍼런스로 저장합니다: "이 릴스 레퍼런스로 저장해줘" + 영상 첨부
5. 만들기를 요청합니다: "이 촬영본으로 릴스 만들어줘"

## 폴더
```
inbox/        받은함 — 다운로드한 레퍼런스를 일단 넣는 곳 ("받은함 정리해줘")
brand/        사업별 폴더 — 소개 · 말투 · 색 · 음성 ID · 상품 · 후기 · 인증 · 사진 · 대표 템플릿
references/   남의 잘된 콘텐츠 — 종류별 · 묶음별, 묶음마다 패턴.md, 전체 색인 목록.md
works/        내가 만든 것 — 브랜드별 · 종류별, 작업 하나 = 폴더 하나, 결과물은 완성/
              works/<브랜드>/목록.md 에서 그 브랜드의 진행 중 · 완성을 한눈에 (연동용은 works/목록.json)
kit/          도구 (양식 · 명령 · 폰트 · 효과음)
```

## 레퍼런스가 쌓이는 방식
저장 → `패턴.md`에 핵심 패턴 2~3개 → 작업에 연결(가져올 것 / 가져오지 않을 것) → 결과가 좋으면 "이거 반응 좋았어"라고 알려 주기.
어떤 레퍼런스를 몇 번 썼고 몇 번 좋았는지는 `references/목록.md`에 자동으로 모입니다.

채팅에 캡처를 붙여 넣으면 파일로 저장이 안 될 수 있습니다. 그럴 때는 파일을 `inbox/`에 넣고 "받은함 정리해줘"라고 하세요.

## 자료는 어디에
- 다음 콘텐츠에서도 또 쓰는 것 → `brand/<사업>/` (후기 · 인증 캡처, 프로필 사진, 자주 쓰는 인서트, 음성 학습 녹음)
- 이번 콘텐츠에만 쓰는 것 → 그 작업의 `원본/` (이번 촬영본, 이번 대본, 이번 녹음)
- 후기 · 인증은 "이 후기 저장해줘"라고 하면 캡처와 함께 원문 · 사용 동의를 표로 정리합니다.

## 작업 목록
"지금 뭐 만들고 있어?", "완성된 거 보여줘"라고 하면 그 브랜드의 `works/<브랜드>/목록.md`를 보여 줍니다. 진행 중인 작업(최근 기록)과 완성된 작업(확정본 · 평가 · 쓴 레퍼런스)이 나뉘어 보입니다. 모든 브랜드를 물으면 Claude가 `works/목록.json`을 읽어 요약합니다.
구글 시트 · Todoist · 노션과 연결할 때는 같은 내용의 `works/목록.json`을 읽으면 됩니다.

## 대표 템플릿
결과가 마음에 들면 "이걸 대표 템플릿으로 해줘". 그 사업의 같은 종류 새 작업은 이 템플릿에서 시작해 모양이 늘 같게 나옵니다.

## 여러 개 한꺼번에
"이 레퍼런스로 릴스 5개 만들어줘"처럼 요청하면 작업마다 에이전트가 하나씩 동시에 만듭니다. 영상 렌더는 하나씩 차례로 합니다.

## 업데이트
`brand/` · `references/` · `works/`의 내 자료는 git에 올라가지 않습니다. 키트를 새 버전으로 받아도 내 자료는 그대로입니다.
