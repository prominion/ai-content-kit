# AI 콘텐츠 키트 v1

잘된 콘텐츠를 레퍼런스로 모으고, 그 패턴으로 상세페이지 · 릴스 · 유튜브롱폼 · 캐러셀 · 영상광고소재를 매번 같은 방식으로 만드는 Claude Code 작업 공간입니다.

## 준비물
- Claude 유료 요금제 + Claude Code (데스크톱 앱 또는 터미널)
- Node 22 이상, FFmpeg, yt-dlp (맥: `brew install node ffmpeg yt-dlp`)
- Higgsfield · Fish Audio 계정과 크레딧 (이미지 · 음성을 쓸 때)
- 그 밖에 저절로 설치되는 것(HyperFrames · whisper · Chrome · 기본 글꼴 Pretendard)과 도구마다 무엇에 쓰이고 돈이 드는지는 **`도구.md`** 한 장에 정리했습니다.

## 시작하기
1. 이 폴더를 Claude Code로 엽니다. **항상 이 폴더에서 엽니다** (하위 폴더에서 열면 설정이 안 읽힙니다).
2. 커넥터는 claude.ai에 연결한 것을 그대로 씁니다 (아래 「연결할 커넥터」). 키트에는 따로 넣지 않았습니다.
3. 사업마다 브랜드를 만듭니다: "브랜드 만들어줘, 이름은 ○○". 이어서 "프로필 같이 채우자"라고 하고 소개 글 · 인스타 링크 · 상세페이지 · 후기 캡처 · 사진을 정리하지 말고 한꺼번에 주세요. Claude가 제자리에 정리하고 빈 곳은 알아서 채웁니다. 꼭 필요한 것만 짧게 물어봅니다. 그 사업의 모든 작업이 이 정보를 먼저 읽습니다.
4. 잘된 콘텐츠를 레퍼런스로 저장합니다: "이 릴스 레퍼런스로 저장해줘" + 영상 첨부
5. 만들기를 요청합니다: "이 촬영본으로 릴스 만들어줘"

## 만드는 것 — 이렇게 말하면 됩니다
| 종류 | 이렇게 말하기 | 결과물 |
|---|---|---|
| 상세페이지 | "상세페이지 만들어줘" + 상품 정보 · 참고할 페이지 링크 | HTML 한 파일 (빌더에 붙이는 코드까지), 휴대폰 폭으로 확인 |
| 릴스 | "이 촬영본으로 릴스 만들어줘" + 촬영본 · 참고할 릴스 | 세로 영상 1080×1920 (컷 · 자막 · 그래픽 · 효과음) |
| 유튜브롱폼 | "이 영상 편집해줘" · "자막 넣어줘" · "영상들 합쳐줘" | 가로 영상 1920×1080, 요청한 편집 그대로 |
| 캐러셀 | "이 영상 내용으로 캐러셀 만들어줘" + 소재 · 참고할 계정 | 인스타 카드 PNG 여러 장 (1080×1350) + 게시 문구 |
| 영상광고소재 | "광고소재 만들어줘" + 내 상세페이지 · 참고할 광고 | 세로 광고 영상 (대본 → 내 음성 → 편집) |

Claude는 재료가 없을 때처럼 꼭 필요한 때만 묻고 끝까지 만듭니다. 재료에 없는 가격 · 일정 · 후기 · 숫자는 지어내지 않고 **「입력 필요」**로 비워 둔 뒤 마지막에 한꺼번에 묻습니다.

## 작업이 끝나면
무엇을 왜 그렇게 정했는지 표로 보여 줍니다. 올릴 버전을 **"v1로 확정"**이라고 말하면 작업 목록에 확정본으로 적히고, 올린 뒤 **"이거 반응 좋았어"**라고 하면 그 작업에 쓴 레퍼런스에 「좋음」이 쌓입니다.

## 연결할 커넥터
claude.ai(또는 데스크톱 앱) → 사용자 지정 → 커넥터 → 「사용자 지정 커넥터 추가」로 넣고, 같은 계정으로 로그인합니다.

| 커넥터 | 주소 | 쓰는 곳 |
|---|---|---|
| Higgsfield | `https://mcp.higgsfield.ai/mcp` | 이미지 · 영상 생성 (상세페이지 · 캐러셀 · 광고소재) |
| Fish Audio | `https://api.fish.audio/mcp` | 내 목소리 학습 · 내레이션 (롱폼 · 광고소재) |

## 폴더
```
inbox/        받은함 — 다운로드한 레퍼런스를 일단 넣는 곳 ("받은함 정리해줘")
brand/        사업별 폴더 — 소개 · 말투 · 색 · 음성 ID · 상품 · 후기 · 인증 · 사진 · 대표 템플릿 · 작업목록
references/   남의 잘된 콘텐츠 — 종류 폴더(상세페이지 · 릴스 · 유튜브롱폼 · 캐러셀 · 영상광고소재) 아래 묶음별, 묶음마다 패턴.md, 전체 색인 목록.md
works/        내가 만든 것 — 종류 폴더(상세페이지-제작 · 릴스-제작 · 유튜브롱폼-제작 · 캐러셀-제작 · 영상광고소재-제작, 강의 목차와 같음) 아래 작업 하나 = 폴더 하나, 결과물은 완성/
              어느 브랜드 작업인지는 작업.md에 적히고, 브랜드별 목록은 brand/<브랜드>/작업목록.md
kit/          도구 (양식 · 명령 · 기본 글꼴 Pretendard · 내가 넣는 폰트 · BGM · 효과음)
```

## 레퍼런스가 쌓이는 방식
저장 → `패턴.md`에 핵심 패턴 2~3개 → 작업에 연결(가져올 것 / 가져오지 않을 것). 어떤 레퍼런스를 몇 번 썼고 몇 번 좋았는지는 `references/목록.md`에 자동으로 모입니다.

채팅에 캡처를 붙여 넣으면 파일로 저장이 안 될 수 있습니다. 그럴 때는 파일을 `inbox/`에 넣고 "받은함 정리해줘"라고 하세요.

## 자료는 어디에
- 다음 콘텐츠에서도 또 쓰는 것 → `brand/<사업>/` (후기 · 인증 캡처, 프로필 사진, 자주 쓰는 인서트, 음성 학습 녹음)
- 이번 콘텐츠에만 쓰는 것 → 그 작업의 `원본/` (이번 촬영본, 이번 대본, 이번 녹음)
- 후기 · 인증은 "이 후기 저장해줘"라고 하면 캡처와 함께 원문 · 사용 동의를 표로 정리합니다.

## 작업 목록
"지금 뭐 만들고 있어?", "완성된 거 보여줘"라고 하면 그 브랜드의 `brand/<브랜드>/작업목록.md`를 보여 줍니다. 진행 중인 작업(최근 기록)과 완성된 작업(확정본 · 평가 · 쓴 레퍼런스)이 나뉘어 보입니다. 모든 브랜드를 물으면 Claude가 `works/목록.json`을 읽어 요약합니다.
구글 시트 · Todoist · 노션 연동은 추후 개발 예정입니다 (같은 내용이 `works/목록.json`에 있습니다).

## 대표 템플릿
결과가 마음에 들면 "이걸 대표 템플릿으로 해줘". 그 사업의 같은 종류 새 작업은 이 템플릿에서 시작해 모양이 늘 같게 나옵니다.
이번만 모양을 새로 하고 싶으면 "새 디자인으로" · "이 레퍼런스처럼 디자인해 줘"라고 말하면 템플릿을 건너뛰고 만듭니다 (템플릿은 그대로 남습니다).

## 여러 개 한꺼번에 (시험 중)
"이 레퍼런스로 릴스 5개 만들어줘"처럼 요청하면 작업마다 에이전트가 하나씩 동시에 만들고, 영상 렌더는 하나씩 차례로 합니다. 아직 실제 작업으로 검증하지 않은 기능이라 하나씩 만드는 쪽을 권합니다.

## 받기 · 업데이트
**맥**: 터미널(응용 프로그램 → 유틸리티)을 열고 아래 한 줄을 붙여 넣습니다.
```bash
curl -fsSL https://raw.githubusercontent.com/prominion/ai-content-kit/main/kit/install/install.sh | bash
```
**윈도우** (아직 검증 전): PowerShell을 열고
```powershell
irm https://raw.githubusercontent.com/prominion/ai-content-kit/main/kit/install/install.ps1 | iex
```
없는 준비물(Node · FFmpeg · yt-dlp)은 물어보고 설치하고, 설치할 폴더를 물으면 Finder에서 폴더를 끌어다 놓거나 Enter(기본 `~/AI콘텐츠키트`)를 누릅니다. 수업 중 기다리지 않게 HyperFrames와 Chrome도 미리 받아 둡니다.
**새 버전으로 바꾸려면 같은 한 줄을 다시 실행**합니다. `brand/` · `references/` · `works/`의 내 자료는 git에 올라가지 않으니 그대로 남습니다.
