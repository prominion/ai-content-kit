# 캐러셀: 소재 → 첫 장 후킹 → 장별 카드

**기본은 묻지 않고 끝까지 간다.** 멈춤 조건일 때만 묻고, 정한 것은 `작업.md` 「5. 기록」에 남긴다. 규격 · 기본값은 `works/carousel/CLAUDE.md`.

## 0. 작업 폴더
- 새 일이면 `npm run new -- carousel "<주제>" --request "<요청 원문>"`. 이어서 하는 일이면 그 폴더 `작업.md`부터.

## 1. 재료 → 「2. 재료」
- 소재: 영상 링크면 자막 · 요약을 `원본/소재.md`에 (링크 함께). 글이면 그대로 저장.
- 레퍼런스: `reference` 스킬 (첨부 · 링크가 왔으면 만들기 전에 저장 → 패턴 → 연결). 안 쓰면 `- 레퍼런스: 없음`.

## 2. 카피 → 「3. 구성」
- 첫 장: 레퍼런스 「핵심 패턴」의 후킹 **구조**(예: 숫자 반전, 질문 → 답 예고)를 내 소재에 맞춰 새로 쓴다. 후보 3개를 쓰고 하나를 고른 이유를 기록한다.
- 장별 표: 장 · 카피 · 그림. 한 장에 한 메시지.
- 숫자 · 사례는 소재에 있는 것만.

## 3. 제작 (`편집/`)
- 카드는 HTML로 짜서 1080×1350 PNG로 찍는다 (글자가 정확하다). 이미지 생성은 배경 · 그림에만 쓴다. 폰트를 정하지 않았으면 Pretendard.
  - `편집/index.html`에 카드마다 `<section class="card">`(1080×1350 고정, `box-sizing:border-box` — 테두리 · 여백이 크기에 더해지면 check ❌, 세로로 나열)를 두고 → `npm run shot -- works/carousel/<작업>/편집/index.html --width 1080 --selector ".card" --out works/carousel/<작업>/완성/v1-레퍼런스형` → `01.png …`.
  - 움직이는 장이 필요하면 GIF는 `npm run gif` (인스타 캐러셀에는 GIF 대신 영상 장이 들어간다 — 요청이 있을 때만).
- 이미지가 필요하면 Higgsfield: 크레딧 확인 → 생성 → `편집/이미지/`.
- 결과: `완성/v1-레퍼런스형/01.png …`.

## 4. 검사
- PNG를 **직접 열어 보고** 글자 잘림 · 겹침을 확인한다.
- `npm run check -- works/carousel/<작업>` ❌가 없을 때까지 고친다.

## 5. 마무리
- 루트 「작업 순서」 5~6 (4. 버전 · 5. 기록 · `상태: 완성` · 확정 · 평가 · 결정 요약 표). 게시 문구는 `완성/<버전>/캡션.md`.
