# 캐러셀: 소재 → 첫 장 후킹 → 장별 카드

**기본은 묻지 않고 끝까지 간다.** 멈춤 조건일 때만 묻고, 정한 것은 `작업.md` 「5. 기록」에 남긴다. 규격 · 기본값은 `works/carousel/CLAUDE.md`.

## 0. 작업 폴더
- 이어서 하는 일이면 그 폴더 `작업.md`부터 읽는다.
- 새 일이면 `npm run new -- carousel "<주제>" --request "<요청 원문>"`.

## 1. 재료 → 「2. 재료」
- 소재: 영상 링크면 자막 · 요약을 `원본/소재.md`에 (링크 함께). 글이면 그대로 저장.
- 레퍼런스: 채팅에 첨부 · 링크가 왔으면 **만들기 전에** `reference` 스킬 0~2 (받기 · 저장 · 패턴), 그다음 3 (연결). 쓰지 않으면 `- 레퍼런스: 없음`.

## 2. 카피 → 「3. 구성」
- 첫 장: 레퍼런스 「핵심 패턴」의 후킹 **구조**(예: 숫자 반전, 질문 → 답 예고)를 내 소재에 맞춰 새로 쓴다. 후보 3개를 쓰고 하나를 고른 이유를 기록한다.
- 장별 표: 장 · 카피 · 그림. 한 장에 한 메시지.
- 숫자 · 사례는 소재에 있는 것만.

## 3. 제작 (`편집/`)
- 카드는 HTML로 짜서 1080×1350 PNG로 찍는다 (글자가 정확하다). 이미지 생성은 배경 · 그림에만 쓴다.
  - 찍는 방법: HyperFrames `snapshot`(카드를 장면으로 두고 시각마다 찍기) 또는 헤드리스 브라우저. **아직 이 키트에서 검증 전** — 처음 성공한 방법을 아래 「겪은 함정」에 적는다.
- 이미지가 필요하면 Higgsfield: 크레딧 확인 → 생성 → `편집/이미지/`.
- 결과: `완성/v1-레퍼런스형/01.png …`.

## 4. 검사
- PNG를 **직접 열어 보고** 글자 잘림 · 겹침을 확인한다.
- `npm run check -- works/carousel/<작업>` ❌가 없을 때까지 고친다.

## 5. 마무리
- `작업.md` 「4. 버전」 · 「5. 기록」 · 머리말 `상태: 완성`. 사용자가 올릴 버전을 정하면 `확정: <버전 폴더>`. 게시 문구는 `완성/<버전>/캡션.md`.
- 결정 요약을 표로.
- 레퍼런스 기록은 `check`가 목록에 자동 반영한다. 사용자가 결과가 좋았다고 하면 `작업.md` 머리말 `평가: 좋음`.
