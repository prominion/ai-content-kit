# 캐러셀: 소재 → 첫 장 후킹 → 장별 카드

규격 · 기본값은 `works/캐러셀-제작/CLAUDE.md`. 작업 폴더 만들기 · 레퍼런스 연결 · 마무리는 루트 「작업 순서」대로 (이 문서는 캐러셀만의 절차).

## 1. 재료 → 「2. 재료」
- 소재: 영상 링크면 자막 · 요약을 `원본/소재.md`에 (링크 함께). 글이면 그대로 저장.
  - 영상 링크 · 파일: `npm run transcribe -- <링크> --lang <원어> --out works/캐러셀-제작/<작업>/원본/전사.md` → 한국어로 정리해 `원본/소재.md`. 장면을 쓸 거면 영상도 `yt-dlp -o 원본/영상.mp4 <링크>`.

## 2. 카피 → 「3. 구성」
- 첫 장: 레퍼런스 「핵심 패턴」의 후킹 **구조**(예: 숫자 반전, 질문 → 답 예고)를 내 소재에 맞춰 새로 쓴다. 후보 3개를 쓰고 하나를 고른 이유를 기록한다.
- 장별 표: 장 · 카피 · 그림. 한 장에 한 메시지.
- 숫자 · 사례는 소재에 있는 것만.

## 3. 제작 (`편집/`)
- 카드는 HTML로 짜서 1080×1350 PNG로 찍는다 (글자가 정확하다). 이미지 생성은 배경 · 그림에만 쓴다. 폰트를 정하지 않았으면 Pretendard.
  - `편집/index.html`에 카드마다 `<section class="card">`(1080×1350 고정, `box-sizing:border-box` — 테두리 · 여백이 크기에 더해지면 check ❌, 세로로 나열)를 두고 → `npm run shot -- works/캐러셀-제작/<작업>/편집/index.html --width 1080 --selector ".card" --out works/캐러셀-제작/<작업>/완성/v1-레퍼런스형` → `01.png …`.
  - 움직이는 장이 필요하면 GIF는 `npm run gif` (인스타 캐러셀에는 GIF 대신 영상 장이 들어간다 — 요청이 있을 때만).
- **그림은 소재 영상의 장면부터.** 소재가 영상이면 정지 화면을 뽑아 보고(루트 「전사 · 정지 화면」) 증거가 되는 장면(기사 · 문서 · 광고 · 후기 화면)을 골라 `편집/이미지/`로 잘라 쓴다. 장면마다 「영상 캡처 · 채널 시각」 표기, 유튜버 얼굴 창은 잘라 내고, 일반인 얼굴 · 몸은 쓰지 않거나 흐리게. "미니멀"은 장식을 줄이라는 뜻이지 그림을 빼라는 뜻이 아니다.
- 영상 장면으로 안 될 때만 Higgsfield: 연결(로그인) · 크레딧 확인 → 생성 → `편집/이미지/`. 연결이 안 돼 있으면 그렇다고 사용자에게 알린다.
- 배경에 옅게 까는 큰 글자처럼 **대비가 낮은 장식은 쓰지 않는다** (안 보이면 없는 것과 같다). 큰 숫자를 쓰면 강조색으로 또렷하게.
- 결과: `완성/v1-레퍼런스형/01.png …` + 게시 문구 `완성/<버전>/캡션.md`.

## 4. 검사
- PNG를 **직접 열어 보고** 글자 잘림 · 겹침을 확인한다.
- `npm run check -- works/캐러셀-제작/<작업>` ❌가 없을 때까지 고친다.

## 멈춤 조건 (이때만 묻는다)
1. 소재가 없을 때
2. 캐러셀 레퍼런스가 하나도 없을 때 → "레퍼런스 없이 할까요, 먼저 찾을까요?"
