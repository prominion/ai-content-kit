# 상세페이지: 재료 → 기획 → 디자인 → HTML 한 파일

규격 · 기본값은 `works/상세페이지-제작/CLAUDE.md`. 작업 폴더 만들기 · 레퍼런스 연결 · 마무리는 루트 「작업 순서」대로 (이 문서는 상세페이지만의 절차).

## 1. 재료 → 「2. 재료」
- 상품: `brand/<브랜드>/products/<상품>.md`. 없으면 `brand` 스킬 「상품 정보 저장」으로 요청에서 받은 정보부터 파일로 만든다. 비어 있는 칸(가격 · 일정 등)은 멈추지 않고 페이지에 「입력 필요」로 표시한다.
- 요청이 "기획해 줘"면 커리큘럼 · 구성은 Claude가 기획하되, `작업.md` 「3. 구성」에 **AI 기획안(사실 아님)**이라고 적는다.
- 내 자료: 후기 · 인증은 `brand/<브랜드>/assets/후기/후기.md` · `assets/인증/인증.md` (사용 동의 「받음」 · 「본인」만). 프로필 · 강의 이미지는 `assets/프로필/`. 대화에 첨부한 후기 · 인증은 먼저 `brand` 스킬로 저장한다.

## 2. 기획 → 「3. 구성」
- 섹션 표: 순서 · 섹션 · 내용 · 근거(재료 경로).
- 카피는 내 상품 재료로 새로 쓴다. 레퍼런스 문장을 고쳐 쓰지 않는다.
- 말투는 `brand/<브랜드>/profile.md` 「말투」.

## 3. 디자인 · 제작 (`편집/`)
- 레퍼런스 「가져올 것」(레이아웃 · 리듬 · 강조 방식) + 브랜드 색 · 폰트. 폰트를 정하지 않았으면 **Pretendard** (페이지에는 jsDelivr CDN `pretendard.min.css` 링크 한 줄).
- 색은 기본으로 브랜드 색. 레퍼런스 배색이 더 맞으면 「3. 구성」에 이유를 적고 쓴다. 글자 색과 바탕색이 비슷해 안 보이는 곳이 없게.
- 이미지가 필요하면 Higgsfield: 연결(로그인) · 크레딧 확인 → 생성 → `편집/이미지/<번호>-<쓰임>.png`. 레퍼런스 그림체를 그대로 따라 그리게 하지 않는다. 연결이 안 돼 있으면 그렇다고 사용자에게 알린다.
- **GIF** (움직임이 메시지일 때 — 전 → 후 변신 · 정렬 · 연결처럼 한 장면):
  1. `npm run gif -- works/상세페이지-제작/<작업>` → `편집/gif/`에 HyperFrames 프로젝트 (800×480, Pretendard 들어 있음). `편집/gif/CLAUDE.md`의 규칙을 따른다.
  2. GIF 여러 개는 한 구성에 2~3초 장면을 이어 붙인다 (`hyperframes-core` 스킬로 작성). `편집/gif/`에서 `npm run check` → `편집/gif/CLAUDE.md`에 적힌 렌더 명령.
  3. `npm run gif -- works/상세페이지-제작/<작업> --cut "01-이름:0-2.6,02-이름:2.6-5.2"` → `편집/이미지/*.gif` (640폭 · 10fps). 정지 화면을 뽑아 직접 본다.
  4. 페이지에는 data URI로 넣고, 각 GIF에 무엇이 움직이는지 `alt`를 쓴다. 숫자 · 성과를 GIF에 지어 넣지 않는다.
- 작은 움직임(등장 · 강조 띠 · 버튼)은 CSS 애니메이션. 스크롤 등장은 스크립트가 없어도 보이게 짠다 (빌더가 스크립트를 지워도 내용이 숨지 않게).

## 4. 버전 · 검사
- `완성/v1-레퍼런스형/index.html` 하나가 기본. "하나 더" · "웹툰형으로도"일 때만 새 폴더(`v2-변형/` · `v3-웹툰형/`).
- 빌더에 올리면 `완성/<버전>/빌더용.html` (`<style>`과 본문만).
- **휴대폰 폭으로 확인**: `npm run shot -- works/상세페이지-제작/<작업>/완성/<버전>/index.html` → `편집/검사/<버전>-375/01.png …`를 전부 Read로 본다 (글자 잘림 · 겹침 · 색 대비 · 가로 넘침).
- `npm run check -- works/상세페이지-제작/<작업>` ❌가 없을 때까지 고친다.

## 멈춤 조건 (이때만 묻는다)
1. 상세페이지 레퍼런스가 하나도 없을 때 → "레퍼런스 없이 할까요, 먼저 찾을까요?"

가격 · 일정 · 강사 · 후기처럼 재료에 없는 사실은 멈추지 않는다. 「입력 필요」로 비워 두고 끝까지 만든 다음, 마무리 때 **빈칸 목록을 한 번에** 묻는다. 빈칸이 남아 있으면 `상태: 완성`으로 하지 않는다.
