# 음성 (Fish Audio)

## 처음 한 번: 내 음성 만들기
1. 조용한 곳에서 1~2분 녹음한 파일을 `brand/<브랜드>/assets/voice/`에 둔다.
2. Fish Audio 커넥터의 음성 복제 도구로 만든다 (크레딧 있는 팀을 고른다).
3. 받은 음성 ID를 `brand/<브랜드>/profile.md` 「음성」에 적는다. 이후 모든 작업이 이 ID를 쓴다.

## 만들기
1. 크레딧을 확인한다. 길면 예상 사용량을 먼저 말한다.
2. 대본을 문장 단위로 나눠 만든다 (한 번에 길게 만들면 한 문장만 고칠 때도 전부 다시 만들어야 한다).
3. 속도는 `brand/<브랜드>/profile.md` 값 → 없으면 기본. 광고는 조금 빠르게.
4. 파일은 작업 폴더 `편집/assets/음성/01.wav, 02.wav …` (영상이 아닌 작업이면 `원본/음성/`).

## 음성 파일 두는 곳
| 음성 | 곳 |
|---|---|
| 목소리 학습용 녹음 (처음 한 번) | `brand/<브랜드>/assets/voice/` |
| 이번 콘텐츠용 직접 녹음 (대본을 읽은 것) | 작업 `원본/음성/` (편집에 쓸 때 `편집/assets/음성/`으로 복사) |
| 이번 콘텐츠용 AI 내레이션 | 작업 `편집/assets/음성/` |
5. `작업.md` 「5. 기록」에 음성 ID · 문장 수 · 쓴 크레딧.

## 지킬 것
- 다른 사람의 목소리를 그 사람 동의 없이 복제하지 않는다.
