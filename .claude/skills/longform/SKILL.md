# 롱폼: 소재 영상 → 번역 + 모션그래픽 + 내 해설

**소재 고르기와 구성 표 확인, 두 번만 묻고 나머지는 끝까지 간다.** 정한 것은 `작업.md` 「5. 기록」에 남긴다. 규격 · 기본값은 `works/longform/CLAUDE.md`.

## 0. 작업 폴더
- 새 일이면 `npm run new -- longform "<주제>" --request "<요청 원문>"`. 이어서 하는 일이면 그 폴더 `작업.md`부터.

## 1. 재료 → 「2. 재료」
- 소재 영상: 사용자가 준 링크, 또는 요청 주제로 찾아 후보 3개(제목 · 채널 · 길이 · 왜 재미있는지)를 보여 주고 고르게 한다.
  링크 · 채널 · 받은 날을 `원본/소재.md`에 적는다. 영상 파일과 자막은 `원본/`에. 자막이 없으면 `편집/`에서 `npx --yes hyperframes@0.8.144 transcribe ../원본/<영상> --model small --language <원어 코드>` (기본 모델은 영어로 번역해 버린다).
- 레퍼런스: `reference` 스킬 (첨부 · 링크가 왔으면 만들기 전에 저장 → 패턴 → 연결). 안 쓰면 `- 레퍼런스: 없음`.
- 내 음성: `brand/<브랜드>/profile.md`의 음성 ID. 없으면 `voice` 스킬로 먼저 만든다.

## 2. 구성 → 「3. 구성」
- 소재 영상 대본을 읽고 쓸 구간을 고른다. 표: 순서 · 원본 구간(시작~끝) · 화자 말(원문 → 번역) · 모션그래픽 · 내 해설.
- 반복 단위는 CLAUDE.md 기본값. 해설은 짧게, 화자의 말을 반복하지 않고 의미 · 적용점을 말한다.
- 구성 표를 사용자에게 한 번 보여 주고 시작한다 (길어서 다시 만들기 비싸다).

## 3. 제작 (`편집/` = HyperFrames 프로젝트, 가로)
- 해설 음성: `voice` 스킬 → `편집/assets/음성/`.
- 번역 자막 · 모션그래픽: `hyperframes` → `general-video` 스킬 (`편집/BRIEF.md`가 있으니 인터뷰 없이 바로 만든다). 인서트용 짧은 그래픽 한 컷만 `motion-graphics`. HyperFrames 명령은 `편집/` 안에서, 항상 버전을 붙여 `npx --yes hyperframes@0.8.144 …` (또는 `npm run check / render`).

## 4. 렌더 · 검사
- 렌더 → `완성/v1/v1.mp4`. 출처는 `완성/v1/설명.md`(유튜브 설명란용).
- 결과 영상에서 정지 화면을 뽑아 **직접 보고** 확인한다 (자막 겹침 · 빈 화면).
- `npm run check -- works/longform/<작업>` ❌가 없을 때까지 고친다.

## 5. 마무리
- 루트 「작업 순서」 5~6 (4. 버전 · 5. 기록 · `상태: 완성` · 확정 · 평가 · 결정 요약 표).
