# 롱폼: 요청대로 편집하는 가로 영상

정해진 틀이 없다. **사용자가 요청한 편집을 그대로 한다.** 규격은 `works/유튜브롱폼-제작/CLAUDE.md` (가로 1920×1080 · 소리 있음). 작업 폴더 만들기 · 레퍼런스 연결 · 마무리는 루트 「작업 순서」대로.

## 1. 재료 → 「2. 재료」
- 사용자가 준 영상 · 소리 · 이미지는 `원본/`으로 복사한다 (원본 파일은 고치지 않는다). 링크면 받아서 (`yt-dlp -o 원본/<이름>.mp4 <링크>`).
- 말을 알아야 하는 편집(컷 · 자막 · 번역 · 요약)이면 `npm run transcribe -- <영상> --lang <원어>`. 화면은 정지 화면으로 함께 본다 (루트 「전사 · 정지 화면」).
- 내 목소리 내레이션이 필요하면 `voice` 스킬 (`brand/<브랜드>/profile.md`의 음성 ID).

## 2. 편집 목록 → 「3. 구성」
- 요청을 편집 목록으로 옮긴다: 순서 · 원본(파일 · 구간) · 할 일(컷 · 이어 붙이기 · 자막 · 그래픽 · 소리).
- 요청이 분명하면 바로 만든다. 길거나 애매하면 목록을 한 번 보여 주고 시작한다 (긴 영상은 다시 만들기 비싸다).

## 3. 제작 (`편집/` = HyperFrames 프로젝트, 가로)
- `편집/CLAUDE.md`의 규칙대로 **`hyperframes-core`** 계약에 맞춰 `index.html`을 쓴다. 쓰는 영상 · 소리는 `편집/assets/`로 복사하고, 영상 구간은 `data-media-start` · `data-duration`으로 잘라 쓴다.
- 출처 표기는 사용자가 원할 때만 (`완성/<버전>/설명.md` 등).

## 4. 렌더 · 검사
- 렌더 전에 `편집/CLAUDE.md`의 snapshot 명령으로 주요 장면을 보고 고친다. 렌더는 한 번에 하나, 직전에 "렌더할까요?" 한 번.
- 렌더 → `완성/v1/v1.mp4`. 결과 영상에서 정지 화면을 뽑아 **직접 본다** (자막 겹침 · 빈 화면 · 잘린 장면). `npm run check -- works/유튜브롱폼-제작/<작업>` ❌가 없을 때까지 고친다.
