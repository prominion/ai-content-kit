# 광고소재: 대본 → 소스 · 음성 → 편집

**대본 확인 한 번 외에는 묻지 않고 끝까지 간다.** 규격 · 기본값은 `works/영상광고소재-제작/CLAUDE.md`. 작업 폴더 만들기 · 레퍼런스 연결 · 마무리는 루트 「작업 순서」대로.

## 1. 재료 → 「2. 재료」
- 홍보할 페이지: 내 상세페이지 작업이면 `works/상세페이지-제작/<작업>/완성/<버전>/`, 외부 링크면 글 전문을 `원본/페이지.md`에 저장.
- 인증 · 후기: `brand/<브랜드>/assets/인증/인증.md` · `assets/후기/후기.md` (사용 동의 「받음」 · 「본인」만, 이 경로를 재료에 적어야 check가 숫자를 대조한다).
- 영상 소스: `brand/<브랜드>/assets/영상소스/` 또는 사용자가 준 폴더 (이번에만 쓰는 것은 복사해서 `원본/`).

## 2. 대본 → `대본.md`
- 레퍼런스 대본의 **구조**(후킹 → 문제 → 증거 → 제안 → 행동 유도)를 내 페이지 내용으로 새로 쓴다.
- 증거(수익 인증 · 후기 · 숫자)는 재료에 있는 것만. 어디서 가져왔는지 대본 옆에 경로로 적는다.
- **대본을 보여 주고 확인받는다.**

## 3. 음성 · 편집 (`편집/` = HyperFrames 프로젝트)
- 음성: `voice` 스킬, 조금 빠르게 → `편집/assets/음성/`.
- 구성 표(「3. 구성」): 장면 · 시간 · 화면(소스/인증/그래픽) · 대사 · 효과음.
- `편집/CLAUDE.md`의 규칙대로 **`hyperframes-core`** 계약에 맞춰 `index.html`을 쓴다. 폰트 · BGM · 효과음은 `brand/<브랜드>/assets/`(목록 `소재.md`) → `kit/assets/`(공용) → 효과음이 없으면 `.claude/skills/media-use/audio/assets/sfx/`(Pixabay, 출처 표기 불필요). 쓰는 파일은 `편집/assets/`로 복사.

## 4. 버전 · 렌더 · 검사
- 렌더 전에 `npx --yes hyperframes@0.8.144 snapshot --at <초,초,…>`로 주요 장면을 보고 고친다. 렌더는 한 번에 하나, 직전에 "렌더할까요?" 한 번 → `완성/v1-레퍼런스형/v1.mp4`.
- 결과 영상에서 정지 화면을 뽑아 **직접 보고** 확인한다. `npm run check -- works/영상광고소재-제작/<작업>` ❌가 없을 때까지. 숫자 경고(⚠️)는 하나씩 출처를 확인한다.
