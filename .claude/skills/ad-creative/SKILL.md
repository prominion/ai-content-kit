# 광고소재: 대본 → 소스 · 음성 → 편집

**대본 확인 한 번 외에는 묻지 않고 끝까지 간다.** 정한 것은 `작업.md` 「5. 기록」에 남긴다. 규격 · 기본값은 `works/ad-creative/CLAUDE.md`.

## 0. 작업 폴더
- 이어서 하는 일이면 그 폴더 `작업.md`부터 읽는다.
- 새 일이면 `npm run new -- ad-creative "<상품>-<후킹 요약>" --request "<요청 원문>"`.

## 1. 재료 → 「2. 재료」
- 홍보할 페이지: 내 상세페이지 작업이면 `works/detail-page/<작업>/완성/<버전>/`, 외부 링크면 글 전문을 `원본/페이지.md`에 저장.
- 인증 · 후기: `brand/<브랜드>/assets/인증/인증.md` · `assets/후기/후기.md` (사용 동의 「받음」 · 「본인」만, 이 경로를 재료에 적어야 check가 숫자를 대조한다).
- 영상 소스: `brand/<브랜드>/assets/영상소스/` 또는 사용자가 준 폴더 (이번에만 쓰는 것은 복사해서 `원본/`).
- 레퍼런스: 채팅에 첨부 · 링크가 왔으면 **만들기 전에** `reference` 스킬 0~2 (받기 · 저장 · 패턴), 그다음 3 (연결). 쓰지 않으면 `- 레퍼런스: 없음`.

## 2. 대본 → `대본.md`
- 레퍼런스 대본의 **구조**(후킹 → 문제 → 증거 → 제안 → 행동 유도)를 내 페이지 내용으로 새로 쓴다.
- 증거(수익 인증 · 후기 · 숫자)는 재료에 있는 것만. 어디서 가져왔는지 대본 옆에 경로로 적는다.
- **대본을 보여 주고 확인받는다.**

## 3. 음성 · 편집 (`편집/` = HyperFrames 프로젝트)
- 음성: `voice` 스킬, 조금 빠르게 → `편집/assets/음성/`.
- 구성 표(「3. 구성」): 장면 · 시간 · 화면(소스/인증/그래픽) · 대사 · 효과음.
- `hyperframes` → `motion-graphics` 스킬. 폰트 · BGM · 효과음은 `brand/<브랜드>/assets/`(목록 `소재.md`) → `kit/assets/`(공용) → 효과음만 없으면 `media-use` 스킬.

## 4. 버전 · 렌더 · 검사
- 렌더는 한 번에 하나 → `완성/v1-레퍼런스형/v1.mp4`, `완성/v2-변형/v2.mp4`.
- 결과 영상에서 정지 화면을 뽑아 **직접 보고** 확인한다.
- `npm run check -- works/ad-creative/<작업>` ❌가 없을 때까지. 숫자 경고(⚠️)는 하나씩 출처를 확인한다.

## 5. 마무리
- `작업.md` 「4. 버전」 · 「5. 기록」 · 머리말 `상태: 완성`. 사용자가 올릴 버전을 정하면 `확정: <버전 폴더>`. 결정 요약을 표로.
- 레퍼런스 기록은 `check`가 목록에 자동 반영한다. 사용자가 결과가 좋았다고 하면 `작업.md` 머리말 `평가: 좋음`.
