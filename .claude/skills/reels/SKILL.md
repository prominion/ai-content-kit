# 릴스: 촬영본 → 레퍼런스 스타일 릴스

규격 · 기본값은 `works/릴스-제작/CLAUDE.md`. 작업 폴더 만들기 · 레퍼런스 연결 · 마무리는 루트 「작업 순서」대로 (이 문서는 릴스만의 절차).

## 1. 재료 → 「2. 재료」
- 촬영본 · 녹음은 `원본/`으로 복사한다.
- 대본: 사용자가 준 대본은 `원본/대본.md`. 촬영본에 여러 버전을 말했으면 하나를 고른다 (요청에 없으면 가장 짧고 센 버전, 기록).
- 브랜드: 색 · 폰트 (`brand/<브랜드>/profile.md`).

## 2. 받아쓰기 · 컷 → 「3. 구성」
- 받아쓰기: `npm run transcribe -- works/릴스-제작/<작업>/원본/<촬영본>` → `원본/전사-<촬영본>.md` + 단어 시간 `편집/transcript.json`. 대본이 있으면 **대본이 정답 글자**, 받아쓰기는 시간만 쓴다.
- 지울 곳: 무음 · 말 더듬음 · 틀린 말 · 다른 곳 보는 구간 · 쓰지 않는 대본 버전. 자를 위치는 whisper 단어 시간이 아니라 **소리로** 정한다 — `ffmpeg -i <파일> -af silencedetect=noise=-30dB:d=0.3 -f null -`로 쉬는 곳을 찾고, 말 중간이 잘리면 소리 크기를 25ms 단위로 보고 옮긴다. 화면은 정지 화면으로 함께 본다 (루트 「전사 · 정지 화면」).
- 구성 표: 장면 · 시간 · 화면(얼굴/그래픽) · 말 · 효과음.

## 3. 편집 (`편집/` = HyperFrames 프로젝트)
- `편집/CLAUDE.md`의 규칙대로 **`hyperframes-core`** 계약에 맞춰 `index.html`을 쓴다. 인서트 그래픽도 같은 구성 안의 장면이다. 장면 · 자막 · 효과음 표가 길면 `build.mjs` 같은 생성 스크립트로 HTML을 만들어도 된다 (표와 스크립트의 시간이 같아야 한다).
- 레퍼런스 「가져올 것」만 따른다. 나머지 표현은 자유.
- 폰트 · BGM · 효과음: `brand/<브랜드>/assets/`(목록 `소재.md`) → `kit/assets/`(공용) → 효과음이 없으면 `.claude/skills/media-use/audio/assets/sfx/`의 무료 효과음 20개(Pixabay 라이선스, 출처 표기 불필요) 또는 무료 사이트(mixkit 등, 라이선스를 「2. 재료」에 적는다). 쓰는 파일은 `편집/assets/`로 복사.
- 배속(1.05배 등)은 렌더 뒤 ffmpeg로 영상 · 소리를 함께 바꾼다 (입 모양 · 자막 싱크 유지).

## 4. 버전 · 렌더 · 검사
- 렌더 전에 `편집/CLAUDE.md`의 snapshot 명령으로 주요 장면을 보고 고친다 (처음 1초 · 얼굴 가림 · 자막 위치 · 빈 화면).
- 렌더는 한 번에 하나. "렌더할까요?" 한 번 묻고 → `편집/`에서 `npm run render` → `완성/v1-레퍼런스형/v1.mp4`로 복사.
- 결과 영상에서 정지 화면을 뽑아 **직접 보고** 확인한다. `npm run check -- works/릴스-제작/<작업>` ❌가 없을 때까지 고친다. 입 모양 · 효과음 크기처럼 정지 화면으로 알 수 없는 것은 「확인 못 함」으로 적는다.

## 멈춤 조건 (이때만 묻는다)
1. 촬영본을 못 찾았거나 후보가 여럿인데 고를 수 없을 때
2. 릴스 레퍼런스가 하나도 없을 때 → "레퍼런스 없이 할까요, 먼저 찾을까요?"
