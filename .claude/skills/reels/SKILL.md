# 릴스: 촬영본 → 레퍼런스 스타일 릴스

**기본은 묻지 않고 끝까지 간다.** 멈춤 조건일 때만 묻고, 정한 것은 `작업.md` 「5. 기록」에 남긴다. 규격 · 기본값은 `works/reels/CLAUDE.md`.

## 0. 작업 폴더
- 이어서 하는 일이면 그 폴더 `작업.md`부터 읽는다.
- 새 일이면 `npm run new -- reels "<요약>" --request "<요청 원문>"` → 촬영본을 `원본/`으로 복사한다.

## 1. 재료 → 「2. 재료」
- 레퍼런스: 채팅에 첨부 · 링크가 왔으면 **만들기 전에** `reference` 스킬 0~2 (받기 · 저장 · 패턴), 그다음 3 (연결). 쓰지 않으면 `- 레퍼런스: 없음`.
- 대본: 사용자가 준 대본은 `원본/대본.md`. 촬영본에 여러 버전을 말했으면 하나를 고른다 (요청에 없으면 가장 짧고 센 버전, 기록).
- 브랜드: 색 · 폰트 (`brand/<브랜드>/profile.md`).

## 2. 받아쓰기 · 컷 → 「3. 구성」
- 받아쓰기: `편집/`에서 `npx hyperframes transcribe ../원본/<촬영본> --model small --language ko` (단어 단위 시간. 기본 모델은 한국어를 영어로 번역하니 반드시 지정). 대본이 있으면 **대본이 정답 글자**, 받아쓰기는 시간만 쓴다.
- 지울 곳: 무음 · 말 더듬음 · 틀린 말 · 다른 곳 보는 구간 · 쓰지 않는 대본 버전. 절차는 `hyperframes` 스킬 `references/routes/talking-head-recut.md`.
- 구성 표: 장면 · 시간 · 화면(얼굴/그래픽) · 말 · 효과음.

## 3. 편집 (`편집/` = HyperFrames 프로젝트)
- `hyperframes` → `general-video` 스킬 순서 (`편집/BRIEF.md`가 있으니 인터뷰 없이 바로 만든다). 인서트용 짧은 그래픽 한 컷만 `motion-graphics`. 모든 `npx hyperframes …`는 `편집/` 안에서.
- 레퍼런스 「가져올 것」만 따른다. 나머지 표현은 자유.
- 폰트 · BGM · 효과음: `brand/<브랜드>/assets/`(폰트 · bgm · 효과음, 목록은 `소재.md`) → `kit/assets/`(공용) → 효과음만 없으면 `media-use` 스킬. 쓰는 파일은 `편집/assets/`로 복사.

## 4. 버전 · 렌더 · 검사
- 렌더는 한 번에 하나. 렌더한다고 알리고 → `편집/`에서 렌더 → `완성/v1-레퍼런스형/v1.mp4`로 복사.
- 결과 영상에서 정지 화면을 뽑아 **직접 보고** 확인한다 (얼굴 가림 · 자막 위치 · 빈 화면).
- `npm run check -- works/reels/<작업>` ❌가 없을 때까지 고친다.

## 5. 마무리
- `작업.md` 「4. 버전」 · 「5. 기록」 · 머리말 `상태: 완성`. 사용자가 올릴 버전을 정하면 `확정: <버전 폴더>`.
- 레퍼런스 기록은 `check`가 목록에 자동 반영한다. 사용자가 결과가 좋았다고 하면 `작업.md` 머리말 `평가: 좋음`.
- 결정 요약을 표로 보여 준다 (무엇 · 왜 · 바꾸려면).

## 멈춤 조건 (이때만 묻는다)
1. 촬영본을 못 찾았거나 후보가 여럿인데 고를 수 없을 때
2. 릴스 레퍼런스가 하나도 없을 때 → "레퍼런스 없이 할까요, 먼저 찾을까요?"
